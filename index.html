the brc-20 experiment

Four lines created history.

On 8 March 2023, the pseudonymous developer Domo (@domodata) introduced BRC-20: an experiment using Ordinal text inscriptions to create fungible tokens on Bitcoin.

Unlike Ethereum’s ERC-20 tokens, BRC-20 does not use a smart contract. Simple JSON text is inscribed onto satoshis, and indexers read the inscriptions in order to track token activity and balances.
